# Cinema

Учебный проект сайта кинотеатра на Flask. Код приложения находится в
`app.py`, данные о фильмах — в `data.py`, HTML-шаблоны — в `templates/`,
стили, JavaScript и изображения — в `static/`.

## Требования

- Python или новее;
- pip для установки зависимостей.

Все команды ниже выполняются из корня репозитория `course-assignments`
(каталог, в котором находятся `cinema/` и `requirements/`).

## Установка

Создайте и активируйте виртуальное окружение.
Если окружение `.venv` уже создано, достаточно активировать его.

Для macOS или Linux:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
```

Для Windows PowerShell:

```powershell
py -3.13 -m venv .venv
.venv\Scripts\Activate.ps1
```

Установите зависимости из [requirements/flask.txt](../requirements/flask.txt):

```bash
python -m pip install --require-hashes -r requirements/flask.txt
```

## Запуск

В активированном виртуальном окружении выполните:

```bash
python -m flask --app cinema.app run --debug
```

Откройте в браузере <http://127.0.0.1:5000/>. Сейчас главная страница
возвращает текст «Привет, пользователь!». Шаблоны и данные о фильмах пока
не подключены к маршрутам приложения.

Режим `--debug` автоматически перезапускает сервер при изменении кода
и включает отладчик. Используйте его только для локальной разработки.
Чтобы запустить приложение без этого режима, уберите `--debug`.

Для остановки сервера нажмите `Ctrl+C` в терминале.

Если порт 5000 занят, укажите другой:

```bash
python -m flask --app cinema.app run --debug --port 5001
```

В этом случае адрес приложения — <http://127.0.0.1:5001/>.

При следующем запуске достаточно активировать окружение и выполнить
команду запуска из корня репозитория. Для выхода из виртуального окружения
выполните `deactivate`.
